# Daily Mini Projects

A growing collection of small, **real, fully-tested** projects — a new one added every day, each in a different prominent language. Every project runs as-is and ships with its own test suite that passes before the code lands here.

## Projects

| # | Project | Language | What it does | Tests |
|---|---------|----------|--------------|-------|
| 1 | [expense-tracker-cli](python/expense-tracker-cli/) | Python | Command-line expense tracker with JSON storage and per-category totals | `python -m unittest` — 6 tests |
| 2 | [unit-converter](javascript/unit-converter/) | JavaScript (Node.js) | Dependency-free unit conversion library: length, weight, temperature | `npm test` — 8 tests |
| 3 | [validation-library](php/validation-library/) | PHP | Tiny input validation library with pipe-style rules (`required\|email\|min:8`) | `php tests/run_tests.php` — 10 checks |

## Rules for every project in this repo

- **Real and working** — no placeholders, no pseudocode; each project runs end to end
- **Tested before it lands** — the test suite must pass locally first
- **Dependency-light** — standard library / built-in tooling wherever possible
- **Documented** — every project folder has its own README with usage and test instructions
